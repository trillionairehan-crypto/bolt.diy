## 조사 결과 — 이미 있던 장치를 재사용했습니다

이 저장소에는 이미 `SHOW_DEV_TOOLS`라는 플래그(`app/utils/featureFlags.ts`, 기본값 꺼짐)가 있었고,
모델/프로바이더 선택, API 키 입력, 시작 템플릿, GitHub/GitLab/Netlify/Vercel/MCP/로컬 모델/클라우드
프로바이더/이벤트 로그 설정 탭, 메시지 사용량 표시 등을 **이미 이 플래그로 숨기고 있었습니다.**
새 플래그를 만들지 않고 이 플래그를 그대로 재사용해서, 새로 만든 것과 원래 있던 것을 합쳐 하나의
스위치로 관리되게 했습니다.

## 1. 뭘 숨겼는지 / 기본 화면에 이제 뭐가 보이는지

  혹시 다른 경로(채팅 요약 안의 코드 배지 클릭 등)로 "코드 보기"가 시도돼도 화면엔 항상 미리보기만

## 2. 개발자 모드를 켜는 방법 (직접 확인용)

`app/utils/featureFlags.ts` 파일을 열어서:
```ts
export const SHOW_DEV_TOOLS = false;
```
이 줄의 `false`를 `true`로 바꾸고 저장하면, 코드/차이점 탭, 파일 트리, 터미널, 다른 배포 방법
드롭다운, "기능"/"데이터" 설정 탭이 전부 원래대로 돌아옵니다. 코드는 하나도 지우지 않았으니
이 한 줄만 바꾸면 됩니다.

---

## 3. 다크모드 다시 켜는 방법

같은 파일(`app/utils/featureFlags.ts`)에서:
```ts
export const DARK_MODE_ENABLED = false;
```
이 줄의 `false`를 `true`로 바꾸면:
- 헤더/사이드바의 다크모드 전환 버튼 3곳이 다시 보입니다.
- 이전에 사용자가 저장해뒀던 "다크 모드로 보고 있었음" 기록(브라우저에 저장된 값)은 지우지
  않고 그대로 두었기 때문에, 플래그를 켜는 순간 그 사용자들은 다시 다크 모드로 보이게 됩니다.
- 시스템(OS)이 다크 모드일 때 자동으로 다크로 시작하는 동작도 함께 돌아옵니다.

CSS/디자인 토큰은 전혀 건드리지 않아서 이 한 줄만으로 완전히 예전 그대로 복원됩니다.

## 4. 브라우저 체크리스트

### PC
1. 새 채팅에서 앱을 하나 만들어 달라고 요청한다.
   - [ ] 워크벤치가 열리면 코드/차이점 탭 전환 버튼 없이 미리보기만 꽉 차게 보이는지.
   - [ ] 레이아웃이 어색하게 비거나 깨져 보이지 않는지.
2. "배포하기" 버튼 옆 화살표(있다면)를 확인한다.
   - [ ] Netlify/Vercel/GitHub/GitLab 옵션 없이 Cloudflare 버튼만 있는지.
3. 사이드바 → 설정(톱니바퀴)을 연다.
   - [ ] "기능", "데이터" 탭이 안 보이는지. 프로필/설정/알림/Supabase는 그대로 있는지.
4. 헤더와 사이드바를 살펴본다.
   - [ ] 다크모드(해/달 아이콘) 전환 버튼이 어디에도 안 보이는지.
   - [ ] 화면이 라이트 테마로 뜨는지 (브라우저/OS를 다크 모드로 바꿔서 새로고침해도 라이트로
     뜨는지 확인).

### 모바일
1. coralred.kr을 휴대폰으로 열고 앱을 하나 만들어 달라고 요청한다.
   - [ ] [대화]/[미리보기] 하단 탭 구조가 예전과 똑같이 동작하는지 (이번 작업으로 안 건드림).
   - [ ] 상단 헤더에 로고, 앱 제목, "배포하기" 버튼만 보이는지 — Netlify/Vercel/GitHub/GitLab
     옵션이 없는지(공용 배포 버튼 부품이라 모바일도 함께 정리됨, §5 참고).
   - [ ] 다크모드 버튼이 어디에도 안 보이는지.
2. [미리보기] 탭에서 앱이 정상적으로 뜨는지 확인 (지난 세션의 셸 초기화 수정이 여전히 잘
   동작하는지 — 이번 작업으로 터미널 관련 코드는 안 건드렸습니다).

## 5. 발견했지만 손대지 않은 것

- **"배포하기" 드롭다운은 데스크톱과 모바일이 같은 부품(`DeployButton.tsx`)을 씁니다.** 그래서
  이번에 다른 배포 방법을 숨긴 게 모바일에도 똑같이 적용됩니다 — 다만 모바일 헤더는 원래도
  "배포하기 버튼만" 보이는 게 목표였어서(지난 모바일 작업), 오히려 원래 의도와 더 잘 맞게
  된 것으로 판단해 그대로 뒀습니다. 혹시 모바일에서만은 다르게 하고 싶으시면 말씀해주세요.
- **"내보내기(채팅 내보내기)" 버튼과 "저장(로컬 폴더 동기화)" 버튼이 코드 탭 전용 영역 안에
  있어서, 코드 탭을 숨기며 같이 안 보이게 됐습니다.** 지시에 명시적으로 언급되지 않았던
  부분이라 일부러 다른 곳으로 옮기지 않고 그대로 뒀습니다 — 혹시 채팅 내보내기를 비개발자에게도
  노출하고 싶으시면 별도로 알려주세요(간단한 위치 이동으로 가능합니다).
- **채팅 메시지 안의 "요약" 팝오버(코드 컨텍스트 배지 클릭 기능)는 그대로 뒀습니다.** 클릭해도
  이제 코드 화면으로 안 넘어가고 미리보기만 계속 보이도록 막았지만, 팝오버 자체(어떤 파일이
  바뀌었는지 요약해서 보여주는 것)는 지시에 없어서 안 건드렸습니다.
- **숨긴 화면에 남아있던 미번역 영어 문구는 지시대로 손대지 않았습니다.**
- **다크모드 CSS/토큰/코드는 지시대로 하나도 지우지 않았습니다** — §3 참고.
