원칙

CSSDA 수상작 90개 분석의 결론: 점수를 가르는 건 기술이 아니라 한 아이디어의 일관성이다. 일관성은 규칙이 보장한다. 규칙이 못 하는 건 "이 브랜드의 아이디어 하나"를 정하는 일 — 그걸 브리프가 사용자에게서 뽑아낸다.

2026-09-11 밤 개정. ① 제품 원칙 전환: "사용자 우선"이 아니라 "결과 우선 — 우리가 정하고 사용자는 확인한다". 세계관·서체·팔레트·모션은 규칙이 결정, 사용자 입력은 사실(사진·숫자·상호·연락)과 아이디어 한 문장에 집중. ② B1은 고정 카드 6장으로 방향만 잡고, 규칙이 고른 상위 3개 세계관을 사용자 브랜드로 개인화 생성(AD 루프, 2~3분, ≈$2)해 G에서 확정. ③ 미디어 생성은 AD 루프(GPT-6 Astra 브리프 → 생성기 → Fable+Astra 이중 심사 → 8.5 미만 재시도, 오브젝트 예산 3개·글자·손 금지) — 생성기는 베이크오프로 세계관별 고정. ④ '단색 컬러 월드' 삭제 → '잉크 그래픽 노블'(Santioni 9.5). 다크는 실사 에디토리얼의 테마 변형.

  1. 애매한 질문 금지. 모든 문항은 Direction Sheet의 필드 하나 이상에 직접 매핑된다. 매핑 없는 질문은 삭제한다. 화면에도 "이 답은 → 히어로 장면"처럼 용도를 표기한다.
  2. 보여주고 고르게 한다. 스타일·팔레트·모션 강도는 글자가 아니라 미리보기 이미지·짧은 영상으로 고른다. 사용자는 형용사를 못 고르지만 그림은 고른다.
  3. 사실만 받는다. 숫자·주소·시간·가격·상호는 사용자가 준 것만 쓴다. 없으면 그 섹션을 통째로 뺀다. 가짜 숫자·가짜 로고 = 즉시 하위권(Numa 8.07).
  4. 미디어는 여기서 끝난다. 사진 업로드·등급 판정·부족분 생성 결정까지 브리프 안에서 완료. 생성 단계에서는 미디어에 대해 아무것도 판단하지 않는다.
  5. 결정론. 같은 브리프 → 같은 Direction Sheet. 매핑 규칙에 LLM을 쓰지 않는다(카피 다듬기 제외). 재생성해도 아트디렉션은 흔들리지 않는다.
  6. 인물 규칙. 실사 인물은 사용자 사진만. 생성 인물은 회화·일러스트 스타일 락일 때만 허용(2026-09-11 결정), 얼굴 클로즈업 없음.
  7. 길이는 나중에 줄인다. 지금은 품질 우선. 선택 문항은 "건너뛰기"가 있고 건너뛴 값은 결정 규칙의 기본값으로 채워진다.

Direction Sheet

브리프의 유일한 출력. 이후 프롬프트·킷·미디어 생성은 이 객체만 읽는다. 사용자 답(brief)과 규칙이 계산한 결정(decided)을 분리해 저장한다 — 규칙이 바뀌면 decided만 재계산.

interface DirectionSheet {
  version: 2;
  brief: {                      // 사용자 답 원본 (A~F)
    industry: string; industryFree?: string;
    idea: { sentence: string; scene: string; sceneType: 'object'|'space'|'hands'|'material'|'landscape'|'abstract' };
    goal?: 'call'|'visit'|'buy'|'inquiry'|'portfolio'|'hire';
    world: { styleLock: 'photo-editorial'|'neoclassical-painting'|'watercolor-illustration'|'product-3d'|'mono-brutal'|'ink-graphic-novel' };
    palette: { accent: string; source: 'chip'|'photo'|'hex' };
    mood: { yes: string[]; no: string[] };
    refs: Array<{ url: string; liked: Array<'color'|'motion'|'photo'|'type'|'mood'>; measured?: RefMetrics }>;
    type?: { preset: 'grotesk'|'serif'|'compact' };
    media: { uploads: Upload[]; videos: Upload[]; generate: boolean; allowPaintedPeople: boolean };
    brand: { nameKo: string; nameEn?: string; logo?: Upload };
    proof: { numbers: Array<{ value: number; unit: string; label: string }> };
    copy: { statement: string };
    contact: { address?: string; phone?: string; hours?: string; closed?: string; instagram?: string; kakao?: string; parking?: string };
    chapters?: Array<{ title: string; body: string }>;
    motion: { level: 'quiet'|'normal'|'cinema' };
    scene3d?: 'none'|'glass-cluster'|'particle-stream'|'type-glitch'|'marble-hall'|'orbit-object'|'shader-hero';
    sound: 'none'|'ambient';
    app: { audience: Q1Value; storage: Q2Value; integrations: string[] };
  };
  decided: {                    // 규칙이 계산 (LLM 없음)

    theme: 'light'|'dark'; accentHex: string; surfaceHex: string; textHex: string;

  };
  promptAdditions: string[];    // 기존 GenerationDirectives 호환 — new-prompt.ts로 흘러가는 문장들
}

테마·서체

  • theme: painting·brutal·illustrated·product·graphic-novel = light. photo-editorial 만 다크 변형: 강조색 명도 L<0.35 또는 무드 '어두운' → dark(Cipher Digital·HACKFIRST). 사용자에게 묻지 않음(수상작 76% 라이트).
  • typePreset: B5 답 우선. 없으면 painting → serif, brutal·fitness·agency → compact, 그 외 grotesk. mood.yes에 '고전적' 있으면 serif, '대담한' 있으면 compact.
  • accent 보정: 회화 = 채도 -20% 명도 -10%(안료 느낌). brutal = 형광 유지. 텍스트·서피스는 accent에서 OKLCH로 파생.

미디어·슬롯

  • peoplePolicy: styleLock ∈ {painting, illustration, graphic-novel} & allowPaintedPeople → painted-only. 그 외 none. 사용자 사진 속 실사 인물은 항상 허용(user-photos-only).
  • 슬롯 배정: 각 슬롯에 A등급 업로드 있으면 그것, 없으면 B등급 + 트리트먼트(산업별 기본: 식음 grain, 서비스 mono, 공간 duotone), 없으면 generate=true일 때 생성, 아니면 슬롯 비움 → 섹션 축소.
  • styleLockPrompt: 세계관별 고정 문자열(painterly.ts STYLE 등 6종) + accent 힌트 + mood.yes 형용사 2개 + mood.no 부정절.
  • video: C4 있으면 upload. 없으면 motion ≠ quiet → seedance(loop). painted-sequence면 mode=sequence(5초 → 프레임 60장 스크럽).
  • estimate: 생성 슬롯 수 × $0.09 + 영상 × $0.15 (+ 시퀀스 3회 생성 후 선택 × $0.45). G 확인 화면에 표시.

킷·섹션·카피

  • motion.level: quiet = reveal만, snap off, marquee off · normal = pinChapters + marquee + preloader · cinema = + sequence/shader hero + snap + cursor.
  • sections: hero, statement(D2), chapters(D4 또는 자동 3), numbers(D1 ≥ 2개일 때만), marquee(normal 이상), contact. 갤러리는 A등급 업로드 ≥ 6장일 때만.
  • copy: headline = A2를 12~14자 × 2줄로 다듬기(LLM, 뜻 유지, 느낌표 금지). sub = A3 한 줄. statement = D2. cta = goal별 고정 문구. 챕터 eyebrow는 영문 모노(Dough/Ferment/Bake) 자동.
  • refs.measured: URL마다 tech/motion 스크립트 실측(idle·journey·pinned·webgl). 결과가 cinema급이면 motion 기본값을 한 단계 올린다.

UI 규칙

  • 한 화면 한 질문. 상단에 챕터 진행(A~G)과 "이 답은 → ○○에 쓰입니다" 라벨.
  • 선택지는 가능한 한 이미지·영상 카드. 카드는 같은 가상의 빵집을 각 옵션으로 렌더한 실제 생성물(캐시).
  • 선택 문항은 "건너뛰기 — 기본값: ○○" 버튼으로 기본값을 미리 보여준다.
  • 자동 저장(localStorage + 로그인 시 서버). 새로고침해도 이어서.
  • G 요약 카드: 원형 이름, 팔레트 칩, 서체 샘플(한글 헤드라인), 히어로 장면 문장, 슬롯표(업로드/생성), 예상 비용·시간. 각 항목 클릭 → 해당 챕터로.
  • 모바일에서도 완주 가능(사진 업로드는 모바일이 오히려 주 경로).
  • 길이 최적화는 나중: 지금은 누락 없이. 완주율·챕터별 이탈은 로그로 남긴다.

수용 기준

  1. 브리프 완료 시 decided 필수 필드 100% 채움(스키마 검증 통과).
  2. 같은 brief 입력 → 바이트 동일 decided(카피 LLM 다듬기 제외). 단위 테스트로 고정.
  3. 24문항 전부 Direction Sheet 필드에 매핑됨. 매핑 없는 문항 0.
  4. 사진 등급기가 실제 폰 사진 30장 세트에서 사람 판정과 80% 이상 일치.
  5. 세계관 6종 × 산업 12종 조합에서 styleLockPrompt·shotList가 전부 생성되고 실사 인물 절이 없음.
  6. G 요약 카드의 예상 비용이 실제 과금과 ±20% 이내.
  7. 생성물이 CSSDA 실측표 통과: 헤딩 ≥ 90px/400, idle ≥ 0.03, journey 0.35~0.6, 핀 ≥ 3(normal 이상), 쿠키 배너 0, 가짜 숫자 0.
